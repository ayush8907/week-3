# Week 3 — Web Development Assignments

A collection of backend and full-stack web development projects built as part of my internship assignments.

## Projects

### 01. User Management API
A REST API for user management, including account operations and authentication.

**Tech stack:** Node.js, Express.js, MongoDB

### 02. Full-Stack To-Do App
A full-stack to-do application with a React frontend and backend API.

**Tech stack:** React, Node.js, Express.js, MongoDB

### 03. Image Upload API
A backend API for handling image uploads using Multer.

**Tech stack:** Node.js, Express.js, Multer

### 04. Image Upload Frontend
A React interface for working with the image upload API.

**Tech stack:** React, Axios

### 05. Task Manager
A task tracking application with user registration, login, task management, and status filtering.

**Tech stack:** React, Axios, Node.js, Express.js, MongoDB, JWT

## Setup

Each project has its own setup and dependencies. Open the corresponding project folder and follow its instructions.

For projects that use environment variables, create a local `.env` file with your own configuration. Never commit credentials, database connection strings, or authentication secrets.
